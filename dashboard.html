How to connect Supabase (cross-device)

  1. Go to supabase.com and create a free account
  2. Create a new project
  3. In SQL Editor, run the SQL from the README to create tables
  4. Copy your Project URL and anon key
  5. Paste them into js/supabase-config.js
  6. The site will then sync products & orders across all devices
